## Цель и контекст

Пользователь сообщил об ошибке `ImageDraw.line() got an unexpected keyword argument 'arrow'` при включении слоя и непонятном назначении переключателя. Сообщение сохранено здесь полностью; исходный скриншот для исполнения не требуется.

Проверено в [app.py](../../sprayframegen/ui/app.py), `SettingsWindow._draw_overlay`, строки 519–551: `draw.line(..., arrow="last")` использует неподдерживаемый аргумент; отдельный вызов Pillow воспроизвёл TypeError. Проверка была на системном Python 3.12, не на целевом 3.14. Контур не учитывает `angle_deg`, вектор масштабируется выдержкой, а итог преобразуется в `L`, теряя цвета. [D08](../../docs/issues/08-user-interface.md) требует ID, геометрические контуры до размытия, векторы скорости и выделение граничных капель только в предпросмотре.

## Ожидаемое поведение и границы

Слой включается без исключения. Стрелки рисуются поддерживаемыми средствами Pillow (линия и наконечник), контуры учитывают геометрию и ориентацию. Видимые обозначения объяснены легендой; цвет сохраняется, если легенда использует цвет. Экспорт и генерация не зависят от переключателя. Нулевой вектор не вызывает ошибку.

Предложение, требующее P01: длина стрелки означает перемещение за межкадровый интервал, согласованное с пикс/кадр. Сейчас код использует выдержку; выбирать другой смысл молча нельзя. P01 фиксирует единицы, длину и поведение для длинных/коротких векторов. Отдельные расхождения чистого предпросмотра с экспортом (ограничение числа капель, отключение эффектов) не входят в задачу.

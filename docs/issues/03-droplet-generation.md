# Реализовать воспроизводимую генерацию размеров, скоростей и формы капель

## Цель и текущее состояние

Получать математическую модель капель из конфигурации и `seed`, независимо от интерфейса и отрисовки. Распределения описаны в ТЗ; сами распределения капель ещё не реализованы. Каркас RNG и его тесты доступны по D02.

## Состояние после выполнения #2 — 15.09.2026

Каркас и конфигурация [#2](https://github.com/EvilSoboL/SprayFrameGen/issues/2) выполнены: доступны единый валидатор, `generation.prepare` и независимые PCG64-потоки модели и шума. Использовать их при реализации распределений и зафиксировать порядок выборок свойств капель. Зависимости #1 и #2 выполнены; задача готова к реализации.

## Результат реализации — 15.09.2026 (локально)

Реализованы `model.Droplet`, `model.sampling.DropletSampler` и
`generation.generate_initial`: параметры первого кадра, независимая от шума
воспроизводимая выборка, последовательные ID, ограничение повторных попыток,
расчёт полуосей по текущему положению. Порядок выборок и пример API описаны
в [README](../../README.md#генерация-параметров-капель-3).

Команда `.venv/Scripts/python.exe -m unittest discover -s tests -v`: **39 тестов
прошли**, включая 11 новых тестов в `tests/test_droplet_generation.py`.
Проверены диапазоны, статистические допуски на 10 000 новых капель, три уровня
концентрации, угловые распределения, сохранение площади, независимость от шума,
повторный запуск, вырожденные случаи и лимит 100 000 попыток.
Параметры траектории хранятся в неизменяемом состоянии; проверка их сохранения
при реальном продвижении между кадрами относится к D04. Рендер и CSV — D05–D06.
Изменения не опубликованы; GitHub #3 остаётся открытым.

## Реализованный объём работ

- Реализовать нормальное и логнормальное распределения размеров с повторной выборкой за пределами диапазона, без обрезания до границ.
- Переводить размеры через масштаб; минимальный эквивалентный диаметр — 3 пикселя.
- При создании выбирать основную группу с вероятностью 95% или группу выбросов с вероятностью 5%. Для основной группы выбирать `theta_deg ~ N(0, direction_std_deg²)` с повторной выборкой вне `[-30°, 30°]`; разброс по умолчанию `10°`, при нулевом разбросе угол равен `0°`. Для выбросов абсолютный угол равномерен в `(30°, 90°)`, вверх и вниз равновероятно.
- Независимо от группы и угла выбирать положительный модуль скорости из нормального распределения с заданными средним, разбросом и границами. Вычислять `Vx=v*cos(theta)`, `Vy=v*sin(theta)`; сохранять группу, направление и скорость на траектории по [D01](../generation_rules.md#8-основное-направление-движения-и-редкие-выбросы).
- На первом кадре выбирать центры по двумерному нормальному распределению вокруг `(W/2, H/2)` с тремя уровнями концентрации и повторной выборкой вне кадра.
- Создавать круг либо эллипс: `a=d_eq/2*sqrt(q)`, `b=d_eq/2/sqrt(q)`. Для реалистичной капли однократно выбирать `q_left` равномерно от `1,00` до `1,35`; выбирать угол поворота и расфокусировку согласно ТЗ и D01. Угол поворота эллипса не подменяет направление скорости.
- Сохранять эквивалентный диаметр, угол, скорость и расфокусировку в состоянии капли на всю её траекторию. Хранить `q_left` для пересчёта текущей формы в D04: в реалистичном режиме `q` линейно стремится к `1` у правой границы с сохранением площади согласно [правилам генерации](../generation_rules.md#9-изменение-вытянутости-капли).
- Разделить детерминированные потоки случайности модели и покадрового шума по [контракту повторяемости](../configuration_contract.md#6-границы-повторяемости). Однородный базовый фон не требует случайной выборки. Предпросмотр не должен расходовать состояние будущего экспорта; переключение шума не изменяет геометрию и CSV.
- Обработать вырожденные случаи и невозможную выборку согласно D01.

## Критерии готовности

- [ ] Повторный запуск с одинаковыми настройками и `seed` в одной сборке и окружении создаёт одинаковые параметры.
- [ ] Все диаметры и скорости находятся в заданных диапазонах; диаметр не меньше 3 пикселей.
- [ ] Геометрия эллипса сохраняет эквивалентный диаметр с относительной погрешностью не более 0,1%.
- [ ] Для размеров и модуля скорости в выборках не менее 10 000 новых капель выполнены статистические допуски раздела 13 при параметрах вдали от границ усечения. Проверки углов учитывают усечение основной группы и равномерность абсолютного угла выбросов; повторные кадры одного ID не считаются новыми выборками.
- [ ] Основная группа и выбросы удовлетворяют своим угловым диапазонам: `±30°` относятся к основной группе, `±90°` и обратное движение недопустимы; группа сохраняется на траектории, точная доля 5% на каждом кадре не навязывается.
- [ ] Проверены фиксированные значения при нулевом разбросе и ошибки недостижимых распределений.
- [ ] При нулевом разбросе модуля величина скорости фиксирована, компоненты соответствуют выбранному углу. Нулевой модуль отклоняется; нулевой угловой разброс основной группы не отключает выбросы.

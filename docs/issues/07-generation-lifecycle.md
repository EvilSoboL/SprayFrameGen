# Реализовать фоновую генерацию, безопасную запись, прогресс и отмену

## Цель и текущее состояние

Обеспечить управляемое создание больших серий и согласованность кадров с разметкой при отмене и ошибках. Эти требования описаны в ТЗ; действующего контроллера генерации нет.

## Состояние после выполнения #2 — 15.09.2026

В [#2](https://github.com/EvilSoboL/SprayFrameGen/issues/2) реализован `generation.prepare`: он очищает метаданные прежней серии и заново создаёт независимые потоки от seed. Использовать этот вход при разработке контроллера. Запись кадров, прогресс и отмена ещё не реализованы; требуется #5.

## Объём работ

- Вынести генерацию из потока интерфейса; определить события прогресса, статуса, завершения и ошибки для D08.
- Перед стартом проверять конфигурацию, возможность записи и свободное место. Оценивать объём изображений и CSV с учётом неопределённости сжатия и предупреждать о крупных сериях.
- Отображать число готовых кадров, общее число, процент и прошедшее время через события контроллера.
- Записывать кадр через временный файл с атомарной фиксацией. Спроектировать согласованную фиксацию изображения, строк CSV и счётчика готовых кадров, включая откат незавершённой записи.
- При отмене завершать текущую безопасную операцию, сохранять готовую часть серии, устанавливать `run.status="cancelled"` и фактический `run.completed_frame_count` по [контракту](../configuration_contract.md#5-метаданные-запуска-и-совместимость).
- При исключении устанавливать `error`, сохранять диагностику в локальный журнал и возвращать понятное русское сообщение; при недоступности носителя явно сообщать невозможность обновить метаданные.
- Во время работы использовать `run.status="running"`, при успехе — `completed`, при исключении — `error`. Хранить время, фактическую папку и окружение в `run`. Не объявлять частичную серию успешной; загруженная частичная серия запускается заново от seed, без возобновления.

## Критерии готовности

- [ ] Отмена до первого кадра и между кадрами даёт корректную папку с фактическим числом готовых кадров.
- [ ] Отмена во время записи не повреждает уже готовые изображения и CSV.
- [ ] Ошибки записи изображения и CSV проверены искусственным воспроизведением сбоев; итоговые данные не содержат несогласованных завершённых кадров и строк.
- [ ] Недостаток места и отсутствие прав записи дают русское сообщение; отказ во время записи не становится молчаливым успехом.
- [ ] Прогресс считает только полностью зафиксированные кадры.
- [ ] Механизм пригоден для отзывчивого интерфейса; итоговая проверка окна выполняется с D08.

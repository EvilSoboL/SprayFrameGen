# Реализовать реалистичные капли, процедурный фон, расфокусировку и размытие движения

## Цель и текущее состояние

Дополнить идеальный рендер визуальными эффектами из ТЗ, сохраняя точные геометрические данные. Реализации пока нет. Все шесть JPEG-референсов найдены и просмотрены в папке пользователя; путь, контрольные суммы и наблюдения зафиксированы в [визуальных референсах](../visual_references.md).

## Объём работ

- Отрисовывать повёрнутые эллипсы по утверждённому [профилю standard-v1](../configuration_contract.md#2-фиксированный-вид-standard-v1): внешний контур 20% нормированного радиуса, непрозрачность внутренности 35%, заданные яркости и смена полярности. Пользовательских регуляторов вида нет. Получать актуальные полуоси из модели D04 с учётом [линейного округления к правой границе](../generation_rules.md#9-изменение-вытянутости-капли).
- Применять отдельно включаемую индивидуальную гауссову расфокусировку к изображению капли до композиции с фоном в обоих режимах; в идеальном режиме по умолчанию выключена. При выключении записывать `blur_sigma_px=0`, сохраняя настроенный диапазон в конфигурации; геометрические размеры CSV не менять.
- Реализовать включаемое размытие движения по скорости, выдержке и масштабу, с временной привязкой D01. Эффект работает в обоих режимах; для реалистичных капель учитывать изменение полуосей в промежуточных положениях в течение выдержки. Левее левой границы использовать `q_left`, правее правой — `q=1`.
- Создавать один однородный базовый фон: `0,15` для тёмного тона и `0,85` для светлого, по умолчанию светлый. Градиент и низкочастотную неоднородность не генерировать.
- Накладывать капли по возрастанию ID, больший ID поверх предыдущих; после композиции капель и фона добавлять независимый покадровый нормальный шум нулевого среднего ко всему изображению.
- Реализовать растеризацию `4×4`, число временных отсчётов, усреднение по средним точкам, гауссово ядро с радиусом `ceil(4×sigma)`, обработку краёв и композицию `P=A×C` по разделу 3 контракта. Использовать `float64`, затем ограничение и округление яркости по единой формуле экспорта.
- Сопоставить результат с доступными `Img000001.jpg`–`Img000006.jpg` из папки, указанной в описании визуальных референсов. Изображения не встраивать и не использовать как фон.

## Пример

При `Vx=3 м/с`, `Vy=4 м/с`, выдержке `20 мкс` и масштабе `10 мкм/пиксель` компоненты следа равны `(6,8)` пикселей, его длина — `10` пикселей.

## Критерии готовности

- [ ] В обоих режимах выключенное размытие движения делает изображение независимым от выдержки.
- [ ] Длина следа проверена на изолированном идеальном круге без шума и расфокусировки: протяжённость ненулевого растрового покрытия вдоль движения до квантования минус диаметр отличается от пути центра не более чем на 1 пиксель (раздел 3 контракта).
- [ ] Угол и расфокусировка одной капли постоянны на её траектории; форма меняется по согласованному линейному закону округления к правой границе с сохранением площади и эквивалентного диаметра.
- [ ] Во время выдержки учитывается изменение формы; CSV описывает полуоси в середине выдержки. После выхода центра вправо частично видимая капля остаётся круглой, а след левее входной границы использует `q_left`.
- [ ] В идеальном режиме проверены четыре сочетания включения расфокусировки и размытия движения; выключенная расфокусировка всегда даёт `blur_sigma_px=0` в CSV, в том числе при включённом размытии движения.
- [ ] Без шума пиксели фона вне областей воздействия капель одинаковы между кадрами; с шумом базовая структура сохраняется, а шум меняется.
- [ ] Базовый фон пространственно однороден для обоих тонов. Порядок наложения соответствует ID; сенсорный шум добавляется после композиции и действует также на капли.
- [ ] Повторный запуск в одной сборке и окружении побайтово воспроизводит изображения для каждого формата; переключение шума не изменяет CSV.
- [ ] Без оптических эффектов профиль даёт расчётную яркость внутренности `0,885` на светлом фоне и `0,115` на тёмном; значения проверяются до квантования в пикселях, целиком лежащих внутри капли.
- [ ] Проведено визуальное сравнение синтетического рендера со всеми шестью доступными референсами; просмотр исходных изображений в D01 сам по себе не закрывает эту проверку.

## Технические основания и зависимости

Зависит от D01 и D05; визуальная приёмка зависит от доступности референсов. Основания: [формирование изображения, строки 188–269](https://github.com/EvilSoboL/SprayFrameGen/blob/master/docs/technical_spec_spray_image_generator.md#L188-L269), [визуальные референсы, строка 533](https://github.com/EvilSoboL/SprayFrameGen/blob/master/docs/technical_spec_spray_image_generator.md#L533).

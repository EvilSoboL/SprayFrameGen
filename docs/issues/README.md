Первая сквозная контрольная версия получается после D05: серия идеальных кадров, CSV и JSON. Это промежуточный результат, не сокращение объёма итоговой версии.

Автоматические тесты расчётов и экспорта создаются вместе с соответствующими модулями. D09 объединяет приёмочные проверки и нагрузочные измерения, а не откладывает всё тестирование до конца разработки.

Общие ограничения версии: без физического моделирования потока, ускорения, столкновений и дробления, 3D, реального фона, RGB, видео, масок сегментации, анализа изображений и прямой интеграции со сторонним анализатором. Основание: [ТЗ, раздел 15](../technical_spec_spray_image_generator.md#15-ограничения-текущей-версии).

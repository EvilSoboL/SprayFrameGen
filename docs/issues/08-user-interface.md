# Создать русскоязычный интерфейс настроек, предпросмотра и экспорта

## Цель и текущее состояние

Обеспечить полный пользовательский сценарий без ручного редактирования JSON. ТЗ перечисляет группы элементов и действия; файлов интерфейса пока нет.

## Объём работ

- Реализовать группы «Серия и камера», «Капли», «Скорость», «Внешний вид», «Фон и шум», «Случайная генерация», «Предпросмотр», «Экспорт».
- Предоставить все согласованные настройки, включая выдержку, переключатель размытия движения, формат и разрядность, ручной `seed` и создание нового значения.
- Реализовать новую конфигурацию, открытие и сохранение JSON через D02; показывать ошибки и предупреждения на русском языке.
- Строить чистый предпросмотр общим рендером с экспортом. Для неизменной конфигурации предпросмотр первого кадра должен соответствовать первому экспортированному кадру с учётом экранного отображения 16-битных данных.
- Отдельно выводить ID, геометрические контуры до размытия, векторы скорости и выделение граничных капель; не передавать этот слой экспортеру.
- Подключить выбор папки, запуск, прогресс, прошедшее время, статус и отмену через D07.
- Фиксировать снимок настроек для начатой серии, исключив изменение параметров текущего запуска через UI.

## Критерии готовности

- [ ] Через интерфейс можно настроить, просмотреть и экспортировать серию, сохранить JSON и повторить её после загрузки.
- [ ] Все пользовательские надписи, ошибки и статусы русскоязычные.
- [ ] Повторный предпросмотр и переключение служебного слоя не меняют экспорт при прежнем `seed`.
- [ ] Служебные элементы видны только в предпросмотре и отсутствуют в файлах.
- [ ] Окно перерисовывается и принимает команду отмены во время большой генерации.
- [ ] Ошибки в полях препятствуют запуску и указывают параметр и причину.

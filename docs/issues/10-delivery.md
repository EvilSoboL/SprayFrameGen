# Подготовить комплект поставки и офлайн-запуск через run.bat на Windows

## Цель и текущее состояние

Передать приложение, которое пользователь может подготовить однократно и затем запускать локально без интернета. ТЗ допускает исходный код и окружение вместо установщика; `run.bat` и README каркаса уже подготовлены в D02, эта задача завершает подготовку приложения к поставке.

## Состояние после выполнения #2 — 15.09.2026

В [#2](https://github.com/EvilSoboL/SprayFrameGen/issues/2) уже подготовлены `run.bat`, README, зависимости и каркас приложения. Запуск проверен на Windows 10 x64 в подготовленном Python-окружении. В этой задаче подготовить окончательный комплект после #9 и проверить Windows 10/11 и офлайн-сценарий.

## Объём работ

- Подготовить `run.bat`, который запускает приложение в локальном окружении и понятно сообщает об отсутствии необходимых компонентов.
- Зафиксировать зависимости и предоставить их локально либо описать однократную подготовку окружения. Обычный запуск не должен обращаться к сети или устанавливать пакеты.
- Подготовить русскоязычный `README.md`: подготовка, запуск, параметры и единицы, `seed`, предпросмотр, экспорт, форматы, отмена и журнал ошибок.
- Включить исходный код, автоматические тесты и инструкции запуска проверок.
- Предоставить [согласованный полный JSON](../examples/config.default.json) с фактической версией приложения и небольшую завершённую серию с кадрами, CSV и конфигурацией по [контракту D01](../configuration_contract.md). Документировать границы точного повтора и фактическое окружение.
- На окончательном комплекте повторить запуск и базовый пользовательский сценарий в Windows 10 и Windows 11 x64 с отключённой сетью.
- Проверить локальное хранение настроек и журналов, отсутствие обязательных сетевых запросов, телеметрии и внешних ресурсов.

## Критерии готовности

- [ ] Комплект содержит все материалы раздела 14 ТЗ.
- [ ] После подготовки окружения `run.bat` запускает приложение без сети на Windows 10/11 x64; результаты проверок зафиксированы.
- [ ] По README можно создать серию, отменить генерацию и повторить результат из JSON.
- [ ] Пример серии имеет `run.status="completed"`, согласованные изображения и CSV и побайтово воспроизводится в зафиксированной сборке и окружении.
- [ ] Указаны версия программы, зависимости и результаты приёмки D09; обнаруженные при проверке поставки дефекты устранены.
